# Senegal Emploi Analytics

## Présentation

Senegal Emploi Analytics est un projet de portfolio consacré
à l'exploration des données trimestrielles relatives à l'emploi
au Sénégal.

Le projet utilise Python pour préparer les données, réaliser
des analyses descriptives et construire un tableau de bord interactif.

## Objectifs

- Préparer et nettoyer les données.
- Explorer les indicateurs d'emploi.
- Étudier les évolutions trimestrielles.
- Comparer les observations par secteur.
- Présenter les résultats dans un tableau de bord interactif.

## Indicateurs étudiés

- Effectifs
- Rémunération
- Heures de travail

## Période étudiée

2019–2025.

## Technologies

- Python
- Pandas
- Matplotlib
- Plotly
- Streamlit
- Excel et CSV
